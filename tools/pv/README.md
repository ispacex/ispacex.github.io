# Конвейер сборки /ksh/pv/ — Parātrīśikāvivaraṇa

Страницы раздела **не пишутся руками**. Они собираются из двух источников:

* санскрит (деванагари и IAST) — переносится с
  [sanskrit-trikashaivism.com](https://www.sanskrit-trikashaivism.com/ru/paratrishika-vivarana-introduction-trika-scriptures-non-dual-shaivism-of-kashmir-ru/540)
  как есть, его никто не набирает заново;
* русский текст — лежит в `ru/*.json` и дописывается по частям.

Так перевод можно доливать сколь угодно долго, ни разу не тронув санскрит и не
рискуя его испортить.

## Шаги

```sh
./fetch.sh                 # исходные страницы  -> src/pvNNN.html
python3 convert.py         # разбор вёрстки     -> blocks/NNN.json
python3 mkcommon.py        # повторяющиеся вставки -> ru/common.json
python3 render.py          # сборка страниц     -> ../../ksh/pv/<часть>/index.md
python3 toc.py             # состояние перевода -> ../../ksh/pv/index.md
```

`render.py` печатает, сколько блоков на каждой странице ещё без перевода, и
помечает их прямо на странице: непереведённый абзац показывается по-английски,
как у источника, в рамке `pv-en`, а вверху страницы стоит предупреждение. Выдать
английский текст за русский конвейер не может по построению.

## Как переводить

```sh
python3 todo.py 793 0 60   # показать непереведённые блоки части 793, блоки 0–60
```

Перевод дописывается в `ru/<id>.json` по номеру блока:

```python
from add import add
add('793', {12: 'русский текст…', 13: '…'})
```

Повторяющиеся куски (преамбула, «Важно:», заголовки «Введение») переводятся один
раз в `mkcommon.py`: ключом там служит **начало** английского текста, а сам ключ
конвейер находит среди разобранных блоков — набирать английский заново не нужно,
опечатка в нём тихо оставила бы абзац непереведённым.

## Что где

| Файл | Что делает |
|---|---|
| `parts.py` | порядок частей, адреса страниц на сайте и у источника |
| `fetch.sh` | скачивает исходные страницы |
| `convert.py` | вёрстка источника → блоки: деванагари, IAST, перевод, пояснение, таблица |
| `mkcommon.py` | переводы повторяющихся вставок |
| `render.py` | блоки + переводы → страницы Jekyll |
| `todo.py` | что ещё не переведено |
| `toc.py` | оглавление с долей переведённого |
| `add.py` | дописать переводы, не потеряв уже написанное |

`src/` и `blocks/` — промежуточные, в репозитории их нет: `fetch.sh` и
`convert.py` восстанавливают их за пару минут.

## Поиск

Отдельно ничего делать не надо. Указатель `/search-index.json` собирает сам
Jekyll, обходя страницы `.md`, — новые части появляются в поиске сразу, как
только собран сайт.
