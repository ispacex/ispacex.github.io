## Строфы 1–10 {#s1}

<p class="pv-pair pv-c" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अथ सप्तमोऽधिकारः।</span><br />
<span class="pv-iast">Atha Saptamo'dhikāraḥ|</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v1" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अथातः सम्प्रवक्ष्यामि मुद्राख्याः शिवशक्तयः।</span><br />
<span class="pv-iast">Athātaḥ sampravakṣyāmi mudrākhyāḥ śivaśaktayaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">याभिः संरक्षितो मन्त्री मन्त्रसिद्धिमवाप्नुयात्॥१॥</span><br />
<span class="pv-iast">Yābhiḥ saṁrakṣito mantrī mantrasiddhimavāpnuyāt||1||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2" data-pv="w1"><span class="pv-sa pv-src" lang="sa">त्रिशूलं च तथा पद्मं शक्तिश्चक्रं सवज्रकम्।</span><br />
<span class="pv-iast">Triśūlaṁ ca tathā padmaṁ śaktiścakraṁ savajrakam|</span><br />
<span class="pv-sa pv-src" lang="sa">दण्डदंष्ट्रे महाप्रेता महामुद्रा खगेश्वरी॥२॥</span><br />
<span class="pv-iast">Daṇḍadaṁṣṭre mahāpretā mahāmudrā khageśvarī||2||</span><br />
<span class="pv-sa pv-src" lang="sa">महोदया कराला च खट्वाङ्गं सकपालकम्।</span><br />
<span class="pv-iast">Mahodayā karālā ca khaṭvāṅgaṁ sakapālakam|</span><br />
<span class="pv-sa pv-src" lang="sa">हलं पाशाङ्कुशं घण्टा मुद्गरस्त्रिशिखोऽपरः॥३॥</span><br />
<span class="pv-iast">Halaṁ pāśāṅkuśaṁ ghaṇṭā mudgarastriśikho'paraḥ||3||</span><br />
<span class="pv-sa pv-src" lang="sa">आवाहस्थापनीरोधा द्रव्यदा नतिरेव च।</span><br />
<span class="pv-iast">Āvāhasthāpanīrodhā dravyadā natireva ca|</span><br />
<span class="pv-sa pv-src" lang="sa">अमृता योगमुद्रेति विज्ञेया वीरवन्दिते॥४॥</span><br />
<span class="pv-iast">Amṛtā yogamudreti vijñeyā vīravandite||4||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v5" data-pv="w1"><span class="pv-sa pv-src" lang="sa">तर्जनीमध्यमानामा दक्षिणस्य प्रसारिताः।</span><br />
<span class="pv-iast">Tarjanīmadhyamānāmā dakṣiṇasya prasāritāḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">कनिष्ठाङ्गुष्ठकाक्रान्तास्त्रिशूलं परिकीर्तितम्॥५॥</span><br />
<span class="pv-iast">Kaniṣṭhāṅguṣṭhakākrāntāstriśūlaṁ parikīrtitam||5||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v6" data-pv="w1"><span class="pv-sa pv-src" lang="sa">पद्माकारौ करौ कृत्वा पद्ममुद्रां प्रदर्शयेत्।</span><br />
<span class="pv-iast">Padmākārau karau kṛtvā padmamudrāṁ pradarśayet|</span><br />
<span class="pv-sa pv-src" lang="sa">संमुखौ प्रसृतौ कृत्वा करानन्तरिताङ्गुली॥६॥</span><br />
<span class="pv-iast">Saṁmukhau prasṛtau kṛtvā karānantaritāṅgulī||6||</span><br />
<span class="pv-sa pv-src" lang="sa">प्रसृते मध्यमे लग्ने कौमार्याः शक्तिरिष्यते।</span><br />
<span class="pv-iast">Prasṛte madhyame lagne kaumāryāḥ śaktiriṣyate|</span><br />
<span class="pv-sa pv-src" lang="sa">उत्तानवाममुष्टेस्तु दक्ष...॥७॥</span><br />
<span class="pv-iast">Uttānavāmamuṣṭestu dakṣa...||7||</span><br />
<span class="pv-sa pv-src" lang="sa">... क्षयेन्मुष्टिं चक्रं नाराचं...।</span><br />
<span class="pv-iast">... kṣayenmuṣṭiṁ cakraṁ nārācaṁ...|</span><br />
<span class="pv-sa pv-src" lang="sa">उत्तानवामकस्योर्ध्वं न्यसेद्दक्षमधोमुखम्॥८॥</span><br />
<span class="pv-iast">Uttānavāmakasyordhvaṁ nyaseddakṣamadhomukham||8||</span><br />
<span class="pv-sa pv-src" lang="sa">कनिष्ठाङ्गुष्ठकौ श्लिष्टौ शेषाः स्युर्मणिबन्धगाः।</span><br />
<span class="pv-iast">Kaniṣṭhāṅguṣṭhakau śliṣṭau śeṣāḥ syurmaṇibandhagāḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">वज्रमुद्रेति विख्याता चैन्द्री सन्तोषकारिका॥९॥</span><br />
<span class="pv-iast">Vajramudreti vikhyātā caindrī santoṣakārikā||9||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v10" data-pv="w1"><span class="pv-sa pv-src" lang="sa">ऊर्द्ध्वप्रसारितो मुष्टिर्दक्षिणोऽङ्गुष्ठगर्भगः।</span><br />
<span class="pv-iast">Ūrddhvaprasārito muṣṭirdakṣiṇo'ṅguṣṭhagarbhagaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">दण्डमुद्रेति विख्याता वैवस्वतकुलप्रिया॥१०॥</span><br />
<span class="pv-iast">Daṇḍamudreti vikhyātā vaivasvatakulapriyā||10||</span></p>

## Строфы 11–24 {#s2}

<p class="pv-pair pv-c" id="s2-sa" data-pv="w1"><span class="pv-sa pv-src" lang="sa">वामतो वक्त्रगां कुर्याद्वाममुष्टेः कनिष्ठिकाम्।</span><br />
<span class="pv-iast">Vāmato vaktragāṁ kuryādvāmamuṣṭeḥ kaniṣṭhikām|</span><br />
<span class="pv-sa pv-src" lang="sa">दंष्ट्रेयं कीर्तिता देवि चामुण्डाकुलनन्दिनी॥११॥</span><br />
<span class="pv-iast">Daṁṣṭreyaṁ kīrtitā devi cāmuṇḍākulanandinī||11||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v12" data-pv="w1"><span class="pv-sa pv-src" lang="sa">वामजानुगतं पादं हस्तौ पृष्ठप्रलम्बिनौ।</span><br />
<span class="pv-iast">Vāmajānugataṁ pādaṁ hastau pṛṣṭhapralambinau|</span><br />
<span class="pv-sa pv-src" lang="sa">विकृते लोचने ग्रीवा भग्ना जिह्वा प्रसारिता॥१२॥</span><br />
<span class="pv-iast">Vikṛte locane grīvā bhagnā jihvā prasāritā||12||</span><br />
<span class="pv-sa pv-src" lang="sa">सर्वयोगिगणस्येष्टा प्रीता योगीश्वरी मता।</span><br />
<span class="pv-iast">Sarvayogigaṇasyeṣṭā prītā yogīśvarī matā|</span><br />
<span class="pv-sa pv-src" lang="sa">हस्तावधोमुखौ पद्भ्यां हृदयान्तं नयेद्बुधः॥१३॥</span><br />
<span class="pv-iast">Hastāvadhomukhau padbhyāṁ hṛdayāntaṁ nayedbudhaḥ||13||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v14" data-pv="w1"><span class="pv-sa pv-src" lang="sa">तिर्यग्मुखान्तमुपरि संमुखावूर्ध्वगौ नयेत्।</span><br />
<span class="pv-iast">Tiryagmukhāntamupari saṁmukhāvūrdhvagau nayet|</span><br />
<span class="pv-sa pv-src" lang="sa">महामुद्रेति विख्याता देहशोधनकर्मणि॥१४॥</span><br />
<span class="pv-iast">Mahāmudreti vikhyātā dehaśodhanakarmaṇi||14||</span><br />
<span class="pv-sa pv-src" lang="sa">सर्वकर्मकरी चैषा योगिनां योगसिद्धये।</span><br />
<span class="pv-iast">Sarvakarmakarī caiṣā yogināṁ yogasiddhaye|</span><br />
<span class="pv-sa pv-src" lang="sa">वद्ध्वा पद्मासनं योगी नाभावक्षेश्वरं न्यसेत्॥१५॥</span><br />
<span class="pv-iast">Vaddhvā padmāsanaṁ yogī nābhāvakṣeśvaraṁ nyaset||15||</span><br />
<span class="pv-sa pv-src" lang="sa">दण्डाकारं तु तं भावं नयेद्यावत्कखत्रयम्।</span><br />
<span class="pv-iast">Daṇḍākāraṁ tu taṁ bhāvaṁ nayedyāvatkakhatrayam|</span><br />
<span class="pv-sa pv-src" lang="sa">निगृह्य तत्र तत्तूर्णं प्रेरयेत् खत्रयेण तु॥१६॥</span><br />
<span class="pv-iast">Nigṛhya tatra tattūrṇaṁ prerayet khatrayeṇa tu||16||</span><br />
<span class="pv-sa pv-src" lang="sa">एतां बद्ध्वा महावीरः खेगतिं प्रतिपद्यते।</span><br />
<span class="pv-iast">Etāṁ baddhvā mahāvīraḥ khegatiṁ pratipadyate|</span><br />
<span class="pv-sa pv-src" lang="sa">अधोमुखस्य दक्षस्य वाममुत्तानमूर्ध्वतः॥१७॥</span><br />
<span class="pv-iast">Adhomukhasya dakṣasya vāmamuttānamūrdhvataḥ||17||</span><br />
<span class="pv-sa pv-src" lang="sa">अनामामध्यमे तस्य वामाङ्गुष्ठेन पीडयेत्।</span><br />
<span class="pv-iast">Anāmāmadhyame tasya vāmāṅguṣṭhena pīḍayet|</span><br />
<span class="pv-sa pv-src" lang="sa">तर्जन्या तत्कनिष्ठां च तर्जनीं च कनिष्ठया॥१८॥</span><br />
<span class="pv-iast">Tarjanyā tatkaniṣṭhāṁ ca tarjanīṁ ca kaniṣṭhayā||18||</span><br />
<span class="pv-sa pv-src" lang="sa">मध्यमानामिकाभ्यां च तदङ्गुष्ठं निपीडयेत्।</span><br />
<span class="pv-iast">Madhyamānāmikābhyāṁ ca tadaṅguṣṭhaṁ nipīḍayet|</span><br />
<span class="pv-sa pv-src" lang="sa">मुद्रा महोदयाख्येयं महोदयकरी नृणाम्॥१९॥</span><br />
<span class="pv-iast">Mudrā mahodayākhyeyaṁ mahodayakarī nṛṇām||19||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v20" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अनामिकाकनिष्ठाभ्यां सृक्वण्यौ प्रविदारयेत्।</span><br />
<span class="pv-iast">Anāmikākaniṣṭhābhyāṁ sṛkvaṇyau pravidārayet|</span><br />
<span class="pv-sa pv-src" lang="sa">जिह्वां च चालयेन्मन्त्री हाहाकारं च कारयेत्॥२०॥</span><br />
<span class="pv-iast">Jihvāṁ ca cālayenmantrī hāhākāraṁ ca kārayet||20||</span><br />
<span class="pv-sa pv-src" lang="sa">क्रुद्धदृष्टिः करालेयं मुद्रा दुष्टभयङ्करी।</span><br />
<span class="pv-iast">Kruddhadṛṣṭiḥ karāleyaṁ mudrā duṣṭabhayaṅkarī|</span><br />
<span class="pv-sa pv-src" lang="sa">वामस्कन्धगतो वाममुष्टिरुच्छ्रिततर्जनी॥२१॥</span><br />
<span class="pv-iast">Vāmaskandhagato vāmamuṣṭirucchritatarjanī||21||</span><br />
<span class="pv-sa pv-src" lang="sa">खट्वाङ्गाख्या स्मृता मुद्रा कपालमधुना शृणु।</span><br />
<span class="pv-iast">Khaṭvāṅgākhyā smṛtā mudrā kapālamadhunā śṛṇu|</span><br />
<span class="pv-sa pv-src" lang="sa">निम्नं पाणितलं दक्षमीषत्सङ्कुचिताङ्गुलि॥२२॥</span><br />
<span class="pv-iast">Nimnaṁ pāṇitalaṁ dakṣamīṣatsaṅkucitāṅguli||22||</span><br />
<span class="pv-sa pv-src" lang="sa">कपालमिति विज्ञेयमधुना हलमुच्यते।</span><br />
<span class="pv-iast">Kapālamiti vijñeyamadhunā halamucyate|</span><br />
<span class="pv-sa pv-src" lang="sa">मुष्टिबद्धस्य दक्षस्य तर्जनी वाममुष्टिना॥२३॥</span><br />
<span class="pv-iast">Muṣṭibaddhasya dakṣasya tarjanī vāmamuṣṭinā||23||</span><br />
<span class="pv-sa pv-src" lang="sa">वक्रतर्जनिना ग्रस्ता हलमुद्रेति कीर्तिता।</span><br />
<span class="pv-iast">Vakratarjaninā grastā halamudreti kīrtitā|</span><br />
<span class="pv-sa pv-src" lang="sa">मुष्ट्या गयोर्दक्षवामयोस्तर्जनीद्वयम्॥२४॥</span><br />
<span class="pv-iast">Muṣṭyā gayordakṣavāmayostarjanīdvayam||24||</span></p>

## Строфы 25–30 {#s3}

<p class="pv-pair pv-c" id="s3-sa" data-pv="w1"><span class="pv-sa pv-src" lang="sa">वामाङ्गुष्ठाग्रसंलग्नं पाशः प्रसृतकुञ्चितः।</span><br />
<span class="pv-iast">Vāmāṅguṣṭhāgrasaṁlagnaṁ pāśaḥ prasṛtakuñcitaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">हले मुष्टिर्यथा वामो दक्षहीनस्तथाङ्कुशः॥२५॥</span><br />
<span class="pv-iast">Hale muṣṭiryathā vāmo dakṣahīnastathāṅkuśaḥ||25||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v26" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अधोमुखस्थिते वामे दक्षिणां तर्जनीं बुधः।</span><br />
<span class="pv-iast">Adhomukhasthite vāme dakṣiṇāṁ tarjanīṁ budhaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">चालयेन्मध्यदेशस्थां घण्टामुद्रा प्रिया मता॥२६॥</span><br />
<span class="pv-iast">Cālayenmadhyadeśasthāṁ ghaṇṭāmudrā priyā matā||26||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v27" data-pv="w1"><span class="pv-sa pv-src" lang="sa">करावूर्ध्वमुखौ कार्यावन्योन्यान्तरिताङ्गुली।</span><br />
<span class="pv-iast">Karāvūrdhvamukhau kāryāvanyonyāntaritāṅgulī|</span><br />
<span class="pv-sa pv-src" lang="sa">अनामे मध्यपृष्ठस्थे तर्जन्यौ मूलपवर्गे॥२७॥</span><br />
<span class="pv-iast">Anāme madhyapṛṣṭhasthe tarjanyau mūlapavarge||27||</span><br />
<span class="pv-sa pv-src" lang="sa">मध्यमे द्वे युते कार्ये कनिष्ठे परुषावधि।</span><br />
<span class="pv-iast">Madhyame dve yute kārye kaniṣṭhe paruṣāvadhi|</span><br />
<span class="pv-sa pv-src" lang="sa">तर्जन्यौ मध्यपार्श्वस्थे विरले परिकल्पिते॥२८॥</span><br />
<span class="pv-iast">Tarjanyau madhyapārśvasthe virale parikalpite||28||</span><br />
<span class="pv-sa pv-src" lang="sa">मुद्गरस्त्रिशिखो ह्येष क्षणादावेशकारकः।</span><br />
<span class="pv-iast">Mudgarastriśikho hyeṣa kṣaṇādāveśakārakaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">कराभ्यामञ्जलिं कृत्वा अनामामूलपर्वगौ॥२९॥</span><br />
<span class="pv-iast">Karābhyāmañjaliṁ kṛtvā anāmāmūlaparvagau||29||</span><br />
<span class="pv-sa pv-src" lang="sa">अङ्गुष्ठौ कल्पयेद्विद्वान्मन्त्रावाहनकर्मणि।</span><br />
<span class="pv-iast">Aṅguṣṭhau kalpayedvidvānmantrāvāhanakarmaṇi|</span><br />
<span class="pv-sa pv-src" lang="sa">मुष्टी द्वावुन्नताङ्गुष्ठौ स्थापनी परिकीर्तिता॥३०॥</span><br />
<span class="pv-iast">Muṣṭī dvāvunnatāṅguṣṭhau sthāpanī parikīrtitā||30||</span></p>

## Строфы 31–36 {#s4}

<p class="pv-pair pv-c" id="s4-sa" data-pv="w1"><span class="pv-sa pv-src" lang="sa">द्वावेव गर्भगाङ्गुष्ठौ विज्ञेया सन्निरोधिनी।</span><br />
<span class="pv-iast">Dvāveva garbhagāṅguṣṭhau vijñeyā sannirodhinī|</span><br />
<span class="pv-sa pv-src" lang="sa">द्रव्यदा तु समाख्याता... त्र संमुखी॥३१॥</span><br />
<span class="pv-iast">Dravyadā tu samākhyātā... tra saṁmukhī||31||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v32" data-pv="w1"><span class="pv-sa pv-src" lang="sa">हृदये संमुखौ हस्तौ संलग्नौ प्रसृताङ्गुली।</span><br />
<span class="pv-iast">Hṛdaye saṁmukhau hastau saṁlagnau prasṛtāṅgulī|</span><br />
<span class="pv-sa pv-src" lang="sa">नमस्कृतिरियं मुद्रा मन्त्रवन्दनकर्मणि॥३२॥</span><br />
<span class="pv-iast">Namaskṛtiriyaṁ mudrā mantravandanakarmaṇi||32||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v33" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अन्योन्यान्तरिताः सर्धाः करयोरङ्गुलीः स्थिताः।</span><br />
<span class="pv-iast">Anyonyāntaritāḥ sardhāḥ karayoraṅgulīḥ sthitāḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">कनिष्ठां दक्षिणां वामेऽनामिकाग्रे नियोजयेत्॥३३॥</span><br />
<span class="pv-iast">Kaniṣṭhāṁ dakṣiṇāṁ vāme'nāmikāgre niyojayet||33||</span><br />
<span class="pv-sa pv-src" lang="sa">दक्षिणे च तथा वामां तर्जनीमध्यमे तथा।</span><br />
<span class="pv-iast">Dakṣiṇe ca tathā vāmāṁ tarjanīmadhyame tathā|</span><br />
<span class="pv-sa pv-src" lang="sa">अङ्गुष्ठौ मध्यमूलस्थौ मुद्रेयममृतप्रभा॥३४॥</span><br />
<span class="pv-iast">Aṅguṣṭhau madhyamūlasthau mudreyamamṛtaprabhā||34||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v35" data-pv="w1"><span class="pv-sa pv-src" lang="sa">दक्षिणं नाभिमूले तु वामस्योपरि संस्थितम्।</span><br />
<span class="pv-iast">Dakṣiṇaṁ nābhimūle tu vāmasyopari saṁsthitam|</span><br />
<span class="pv-sa pv-src" lang="sa">तर्जन्यङ्गुष्ठकौ लग्नौ उच्छ्रितौ योगकर्मणि॥३५॥</span><br />
<span class="pv-iast">Tarjanyaṅguṣṭhakau lagnau ucchritau yogakarmaṇi||35||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v36" data-pv="w1"><span class="pv-sa pv-src" lang="sa">एवं मुद्रागणं मन्त्री बध्नीयाद्धृदये बुधः।</span><br />
<span class="pv-iast">Evaṁ mudrāgaṇaṁ mantrī badhnīyāddhṛdaye budhaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">सर्वासां वाचकश्चासां ॐ ह्रीं नाम ततो नमः॥३६॥</span><br />
<span class="pv-iast">Sarvāsāṁ vācakaścāsāṁ oṁ hrīṁ nāma tato namaḥ||36||</span></p>

<p class="pv-pair pv-c" data-pv="w1"><span class="pv-sa pv-src" lang="sa">इति श्रीमालिनीविजयोत्तरे तन्त्रे मुद्राधिकारः सप्तमः॥७॥</span><br />
<span class="pv-iast">Iti śrīmālinīvijayottare tantre mudrādhikāraḥ saptamaḥ||7||</span></p>
