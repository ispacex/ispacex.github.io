## Строфы 1–10 {#s1}

<p class="pv-copy nosearch pv-anchor" id="s1-sa"><button type="button" data-pv-copy="w1" data-pv-what="pv-sa">Копировать санскрит</button> <button type="button" data-pv-copy="w1" data-pv-what="pv-iast">Копировать транслитерацию</button></p>

<p class="pv-pair pv-c" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अथ षोडशोऽधिकारः।</span><br />
<span class="pv-iast">Atha Ṣoḍaśo'dhikāraḥ|</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v1" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अथ गर्वमयीं दिव्यां धारणां धारणोत्तमाम्।</span><br />
<span class="pv-iast">Atha garvamayīṁ divyāṁ dhāraṇāṁ dhāraṇottamām|</span><br />
<span class="pv-sa pv-src" lang="sa">महागर्वकरीं वक्ष्ये योगिनां योगवन्दिते॥१॥</span><br />
<span class="pv-iast">Mahāgarvakarīṁ vakṣye yogināṁ yogavandite||1||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2" data-pv="w1"><span class="pv-sa pv-src" lang="sa">षोडशारं स्मरेच्चक्रमात्मदेहमनन्यधीः।</span><br />
<span class="pv-iast">Ṣoḍaśāraṁ smareccakramātmadehamananyadhīḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">एषोऽहमिति सञ्चिन्त्य स्वकार्यपरिवारितम्॥२॥</span><br />
<span class="pv-iast">Eṣo'hamiti sañcintya svakāryaparivāritam||2||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v3" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अप्रधृष्यो भवेद्योगी वत्सरत्रितयेन तु।</span><br />
<span class="pv-iast">Apradhṛṣyo bhavedyogī vatsaratritayena tu|</span><br />
<span class="pv-sa pv-src" lang="sa">ममत्वमच्युतं तस्य भवेत्सर्वत्र कुत्रचित्॥३॥</span><br />
<span class="pv-iast">Mamatvamacyutaṁ tasya bhavetsarvatra kutracit||3||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v4" data-pv="w1"><span class="pv-sa pv-src" lang="sa">तादृग्रूपस्य चक्रस्य नाभिं मूर्तिं स्वकां स्मरन्।</span><br />
<span class="pv-iast">Tādṛgrūpasya cakrasya nābhiṁ mūrtiṁ svakāṁ smaran|</span><br />
<span class="pv-sa pv-src" lang="sa">चिन्तयेत्सर्वमेवाहं मयि सर्वमवस्थितम्॥४॥</span><br />
<span class="pv-iast">Cintayetsarvamevāhaṁ mayi sarvamavasthitam||4||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v5" data-pv="w1"><span class="pv-sa pv-src" lang="sa">ततोऽहङ्कारविज्ञानं प्राप्नोतीति किमद्भुतम्।</span><br />
<span class="pv-iast">Tato'haṅkāravijñānaṁ prāpnotīti kimadbhutam|</span><br />
<span class="pv-sa pv-src" lang="sa">हृच्चक्रे समनुध्यायन्मत्स्वरूपमतन्द्रितः॥५॥</span><br />
<span class="pv-iast">Hṛccakre samanudhyāyanmatsvarūpamatandritaḥ||5||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v6" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अर्कलोकमवाप्नोति गर्वावरणजं फलम्।</span><br />
<span class="pv-iast">Arkalokamavāpnoti garvāvaraṇajaṁ phalam|</span><br />
<span class="pv-sa pv-src" lang="sa">बिम्बादिकं क्रमात्सर्वं चिन्तयन्नीललोहितम्॥६॥</span><br />
<span class="pv-iast">Bimbādikaṁ kramātsarvaṁ cintayannīlalohitam||6||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v7" data-pv="w1"><span class="pv-sa pv-src" lang="sa">तद्भवं सर्वमाप्नोति दशावस्थाप्रचोदितम्।</span><br />
<span class="pv-iast">Tadbhavaṁ sarvamāpnoti daśāvasthāpracoditam|</span><br />
<span class="pv-sa pv-src" lang="sa">इति गर्वमयी प्रोक्ता प्रजापतिगुणप्रदा॥७॥</span><br />
<span class="pv-iast">Iti garvamayī proktā prajāpatiguṇapradā||7||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v8" data-pv="w1"><span class="pv-sa pv-src" lang="sa">उद्यदादित्यबिम्बाभं हृदि पद्ममनुस्मरन्।</span><br />
<span class="pv-iast">Udyadādityabimbābhaṁ hṛdi padmamanusmaran|</span><br />
<span class="pv-sa pv-src" lang="sa">धर्मादिभावसंयुक्तमष्टपत्रं सकर्णिकम्॥८॥</span><br />
<span class="pv-iast">Dharmādibhāvasaṁyuktamaṣṭapatraṁ sakarṇikam||8||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v9" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मासेन स्थिरबुद्धिः स्यात्षड्भिः श्रुतिधरो भवेत्।</span><br />
<span class="pv-iast">Māsena sthirabuddhiḥ syātṣaḍbhiḥ śrutidharo bhavet|</span><br />
<span class="pv-sa pv-src" lang="sa">त्रिभिरब्दैः स्वयं कर्ता शास्त्राणां सम्प्रजायते॥९॥</span><br />
<span class="pv-iast">Tribhirabdaiḥ svayaṁ kartā śāstrāṇāṁ samprajāyate||9||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v10" data-pv="w1"><span class="pv-sa pv-src" lang="sa">स्वां तत्र चिन्तयेन्मूर्तिं बुद्धितत्त्वं प्रपश्यति।</span><br />
<span class="pv-iast">Svāṁ tatra cintayenmūrtiṁ buddhitattvaṁ prapaśyati|</span><br />
<span class="pv-sa pv-src" lang="sa">तदीशज्ञानमाप्नोति ब्रह्माणमनुचिन्तयन्॥१०॥</span><br />
<span class="pv-iast">Tadīśajñānamāpnoti brahmāṇamanucintayan||10||</span></p>

## Строфы 11–20 {#s2}

<p class="pv-pair pv-c" id="s2-sa" data-pv="w1"><span class="pv-sa pv-src" lang="sa">वेदानुद्गिरते सप्त समाधिस्थोऽथवा मुनिः।</span><br />
<span class="pv-iast">Vedānudgirate sapta samādhistho'thavā muniḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">सुस्थिरास्ते सदाभ्यासादनधीता अपि स्फुटम्॥११॥</span><br />
<span class="pv-iast">Susthirāste sadābhyāsādanadhītā api sphuṭam||11||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v12" data-pv="w1"><span class="pv-sa pv-src" lang="sa">बिम्बादिकं क्रमात्सर्वं पूर्वोक्तमनुचिन्तयन्।</span><br />
<span class="pv-iast">Bimbādikaṁ kramātsarvaṁ pūrvoktamanucintayan|</span><br />
<span class="pv-sa pv-src" lang="sa">प्राप्नोति ब्राह्ममैश्वर्यं बुद्ध्यावरणमाश्रितम्॥१२॥</span><br />
<span class="pv-iast">Prāpnoti brāhmamaiśvaryaṁ buddhyāvaraṇamāśritam||12||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v13" data-pv="w1"><span class="pv-sa pv-src" lang="sa">हृदि बिम्बं रवेर्ध्यायंस्तदन्तः सोममण्डलम्।</span><br />
<span class="pv-iast">Hṛdi bimbaṁ raverdhyāyaṁstadantaḥ somamaṇḍalam|</span><br />
<span class="pv-sa pv-src" lang="sa">एवमभ्यसतस्तस्य षण्मासादुपजायते॥१३॥</span><br />
<span class="pv-iast">Evamabhyasatastasya ṣaṇmāsādupajāyate||13||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v14" data-pv="w1"><span class="pv-sa pv-src" lang="sa">दिव्यचक्षुरजायासात्सिद्धिः स्याद्वत्सरत्रयात्।</span><br />
<span class="pv-iast">Divyacakṣurajāyāsātsiddhiḥ syādvatsaratrayāt|</span><br />
<span class="pv-sa pv-src" lang="sa">स्वदेहं चिन्तयंस्तत्र गुणज्ञानमवाप्स्यति॥१४॥</span><br />
<span class="pv-iast">Svadehaṁ cintayaṁstatra guṇajñānamavāpsyati||14||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15" data-pv="w1"><span class="pv-sa pv-src" lang="sa">लिङ्गाकारं स्मरन्दीप्तं तदीशत्वमवाप्नुयात्।</span><br />
<span class="pv-iast">Liṅgākāraṁ smarandīptaṁ tadīśatvamavāpnuyāt|</span><br />
<span class="pv-sa pv-src" lang="sa">बिम्बादि पूर्ववद्ध्यायन्दशकं दशकात्मकम्॥१५॥</span><br />
<span class="pv-iast">Bimbādi pūrvavaddhyāyandaśakaṁ daśakātmakam||15||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v16" data-pv="w1"><span class="pv-sa pv-src" lang="sa">फलमाप्नोत्यसन्देहाद्गुणावरणसंस्थितम्।</span><br />
<span class="pv-iast">Phalamāpnotyasandehādguṇāvaraṇasaṁsthitam|</span><br />
<span class="pv-sa pv-src" lang="sa">चतुर्विंशत्यमी प्रोक्ताः प्रत्येकं दशपञ्चधा॥१६॥</span><br />
<span class="pv-iast">Caturviṁśatyamī proktāḥ pratyekaṁ daśapañcadhā||16||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v17" data-pv="w1"><span class="pv-sa pv-src" lang="sa">धारणाः क्ष्मादितत्त्वानां समासाद्योगिनां हिताः।</span><br />
<span class="pv-iast">Dhāraṇāḥ kṣmāditattvānāṁ samāsādyogināṁ hitāḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">त्रयोदशात्मके भेदे षडन्याः संस्थिता यथा॥१७॥</span><br />
<span class="pv-iast">Trayodaśātmake bhede ṣaḍanyāḥ saṁsthitā yathā||17||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v18" data-pv="w1"><span class="pv-sa pv-src" lang="sa">योगिनामनुवर्ण्यन्ते तथा योगप्रसिद्धये।</span><br />
<span class="pv-iast">Yogināmanuvarṇyante tathā yogaprasiddhaye|</span><br />
<span class="pv-sa pv-src" lang="sa">देहं मुक्त्वा स्वरूपेण नान्यत् किञ्चिदिति स्मरेत्॥१८॥</span><br />
<span class="pv-iast">Dehaṁ muktvā svarūpeṇa nānyat kiñciditi smaret||18||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v19" data-pv="w1"><span class="pv-sa pv-src" lang="sa">सितपद्मासनासीनं मण्डलत्रितयोपरि।</span><br />
<span class="pv-iast">Sitapadmāsanāsīnaṁ maṇḍalatritayopari|</span><br />
<span class="pv-sa pv-src" lang="sa">एवमत्र स्थिरीभूते मासमात्रेण योगवित्॥१९॥</span><br />
<span class="pv-iast">Evamatra sthirībhūte māsamātreṇa yogavit||19||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v20" data-pv="w1"><span class="pv-sa pv-src" lang="sa">सर्वव्याधिविनिर्मुक्तो भवतीति किमद्भुतम्।</span><br />
<span class="pv-iast">Sarvavyādhivinirmukto bhavatīti kimadbhutam|</span><br />
<span class="pv-sa pv-src" lang="sa">षण्मासादस्य विज्ञानं जायते पृथिवीतले॥२०॥</span><br />
<span class="pv-iast">Ṣaṇmāsādasya vijñānaṁ jāyate pṛthivītale||20||</span></p>

## Строфы 21–30 {#s3}

<p class="pv-pair pv-c" id="s3-sa" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अब्दाज्जरादिनिर्मुक्तस्त्रिभिः पुंस्तत्त्वदृग्भवेत्।</span><br />
<span class="pv-iast">Abdājjarādinirmuktastribhiḥ puṁstattvadṛgbhavet|</span><br />
<span class="pv-sa pv-src" lang="sa">हृदधः पङ्कजेऽत्रैव द्वादशार्धाङ्गुलाः तनुम्॥२१॥</span><br />
<span class="pv-iast">Hṛdadhaḥ paṅkaje'traiva dvādaśārdhāṅgulāḥ tanum||21||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v22" data-pv="w1"><span class="pv-sa pv-src" lang="sa">हृदन्ते भावयेत्स्वान्यां षण्मासान्मृत्युजिद्भवेत्।</span><br />
<span class="pv-iast">Hṛdante bhāvayetsvānyāṁ ṣaṇmāsānmṛtyujidbhavet|</span><br />
<span class="pv-sa pv-src" lang="sa">त्रिभिरब्दैः समाप्नोति पुंस्तत्त्वेश्वरतुल्यताम्॥२२॥</span><br />
<span class="pv-iast">Tribhirabdaiḥ samāpnoti puṁstattveśvaratulyatām||22||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v23" data-pv="w1"><span class="pv-sa pv-src" lang="sa">बिम्बादौ पूर्ववत्सर्वं तत्र सञ्चिन्तिते सति।</span><br />
<span class="pv-iast">Bimbādau pūrvavatsarvaṁ tatra sañcintite sati|</span><br />
<span class="pv-sa pv-src" lang="sa">फलमाप्नोत्यसन्देहात्पुरुषावरणस्थितम्॥२३॥</span><br />
<span class="pv-iast">Phalamāpnotyasandehātpuruṣāvaraṇasthitam||23||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v24" data-pv="w1"><span class="pv-sa pv-src" lang="sa">एतद्वेदान्तविज्ञानं समासादुपवर्णितम्।</span><br />
<span class="pv-iast">Etadvedāntavijñānaṁ samāsādupavarṇitam|</span><br />
<span class="pv-sa pv-src" lang="sa">कपिलस्य पुरा प्रोक्तमेतद्विस्तरशो मया॥२४॥</span><br />
<span class="pv-iast">Kapilasya purā proktametadvistaraśo mayā||24||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v25" data-pv="w1"><span class="pv-sa pv-src" lang="sa">शरत्सन्ध्याभ्रसङ्घाभं स्वदेहमनुचिन्तयन्।</span><br />
<span class="pv-iast">Śaratsandhyābhrasaṅghābhaṁ svadehamanucintayan|</span><br />
<span class="pv-sa pv-src" lang="sa">वीतरागत्वमाप्नोति षड्भिर्मासैर्न संशयः॥२५॥</span><br />
<span class="pv-iast">Vītarāgatvamāpnoti ṣaḍbhirmāsairna saṁśayaḥ||25||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v26" data-pv="w1"><span class="pv-sa pv-src" lang="sa">जरामरणनिर्मुक्तो वर्षेणैवोपजायते।</span><br />
<span class="pv-iast">Jarāmaraṇanirmukto varṣeṇaivopajāyate|</span><br />
<span class="pv-sa pv-src" lang="sa">त्र्यब्दाज्ज्ञानमवाप्नोति रागावरणजं महत्॥२६॥</span><br />
<span class="pv-iast">Tryabdājjñānamavāpnoti rāgāvaraṇajaṁ mahat||26||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v27" data-pv="w1"><span class="pv-sa pv-src" lang="sa">रक्तं सञ्चिन्तयेद्देहं सम्पूर्णाभ्रोपरिस्थितम्।</span><br />
<span class="pv-iast">Raktaṁ sañcintayeddehaṁ sampūrṇābhroparisthitam|</span><br />
<span class="pv-sa pv-src" lang="sa">मासषट्कमनुद्विग्नो वीतरागत्वसिद्धये॥२७॥</span><br />
<span class="pv-iast">Māsaṣaṭkamanudvigno vītarāgatvasiddhaye||27||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v28" data-pv="w1"><span class="pv-sa pv-src" lang="sa">स्मरन्संवत्सरे सम्यङ्मृत्युना न प्रपीड्यते।</span><br />

<span class="pv-iast">Vetti bhuṅkte ca satataṁ na ca tasmātprahīyate|</span><br />
<span class="pv-sa pv-src" lang="sa">तत्रस्थे तेजसि ध्याते सर्वदेहविसर्पिणि॥५९॥</span><br />
<span class="pv-iast">Tatrasthe tejasi dhyāte sarvadehavisarpiṇi||59||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v60" data-pv="w1"><span class="pv-sa pv-src" lang="sa">पूर्वोक्तं सर्वमाप्नोति तत्कालक्रमयोगतः।</span><br />
<span class="pv-iast">Pūrvoktaṁ sarvamāpnoti tatkālakramayogataḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">अथोर्ध्वव्यापिनि ध्याने तत्र तस्मादखण्डितः॥६०॥</span><br />
<span class="pv-iast">Athordhvavyāpini dhyāne tatra tasmādakhaṇḍitaḥ||60||</span></p>

## Строфы 61–68 {#s7}

<p class="pv-pair pv-c" id="s7-sa" data-pv="w1"><span class="pv-sa pv-src" lang="sa">सर्वं मन्त्रेश्वरेशत्वान्न भूयोऽपि निवर्तते।</span><br />
<span class="pv-iast">Sarvaṁ mantreśvareśatvānna bhūyo'pi nivartate|</span><br />
<span class="pv-sa pv-src" lang="sa">एवं ललाटदेशेऽपि महादीप्तमनुस्मरन्॥६१॥</span><br />
<span class="pv-iast">Evaṁ lalāṭadeśe'pi mahādīptamanusmaran||61||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v62" data-pv="w1"><span class="pv-sa pv-src" lang="sa">प्रपश्यत्यचिरादेव वर्णाष्टकयुतं क्रमात्।</span><br />
<span class="pv-iast">Prapaśyatyacirādeva varṇāṣṭakayutaṁ kramāt|</span><br />
<span class="pv-sa pv-src" lang="sa">इन्द्रनीलप्रतीकाशं शिखिकण्ठसमद्युति॥६२॥</span><br />
<span class="pv-iast">Indranīlapratīkāśaṁ śikhikaṇṭhasamadyuti||62||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v63" data-pv="w1"><span class="pv-sa pv-src" lang="sa">राजावर्तनिभं चान्यत्तथा वैदूर्यसन्निभम्।</span><br />
<span class="pv-iast">Rājāvartanibhaṁ cānyattathā vaidūryasannibham|</span><br />
<span class="pv-sa pv-src" lang="sa">पुष्परागनिभं चान्यत्प्रवालकसमद्युति॥६३॥</span><br />
<span class="pv-iast">Puṣparāganibhaṁ cānyatpravālakasamadyuti||63||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v64" data-pv="w1"><span class="pv-sa pv-src" lang="sa">पद्मरागप्रतीकाशमन्यच्चन्द्रसमद्युति।</span><br />
<span class="pv-iast">Padmarāgapratīkāśamanyaccandrasamadyuti|</span><br />
<span class="pv-sa pv-src" lang="sa">तां दृष्ट्वा परमां ज्योत्स्नां दिव्यज्ञानं प्रवर्तते॥६४॥</span><br />
<span class="pv-iast">Tāṁ dṛṣṭvā paramāṁ jyotsnāṁ divyajñānaṁ pravartate||64||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v65" data-pv="w1"><span class="pv-sa pv-src" lang="sa">विहारपादचारादि ततः सर्वं प्रवर्तते।</span><br />
<span class="pv-iast">Vihārapādacārādi tataḥ sarvaṁ pravartate|</span><br />
<span class="pv-sa pv-src" lang="sa">अधोर्ध्वं व्यापिनि ध्याते न तस्माच्च्यवते पदात्॥६५॥</span><br />
<span class="pv-iast">Adhordhvaṁ vyāpini dhyāte na tasmāccyavate padāt||65||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v66" data-pv="w1"><span class="pv-sa pv-src" lang="sa">इत्येतत्सर्वमाख्यातं लक्ष्यभेदव्यवस्थितम्।</span><br />
<span class="pv-iast">Ityetatsarvamākhyātaṁ lakṣyabhedavyavasthitam|</span><br />
<span class="pv-sa pv-src" lang="sa">अधुना चित्तभेदोऽपि समासादुपदिश्यते॥६६॥</span><br />
<span class="pv-iast">Adhunā cittabhedo'pi samāsādupadiśyate||66||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v67" data-pv="w1"><span class="pv-sa pv-src" lang="sa">पिशाचानन्तपर्यन्तगुणाष्टकसमीहया।</span><br />
<span class="pv-iast">Piśācānantaparyantaguṇāṣṭakasamīhayā|</span><br />
<span class="pv-sa pv-src" lang="sa">तत्तद्रूपगुणं कुर्यात्सम्यगीशे स्थिरं मनः॥६७॥</span><br />
<span class="pv-iast">Tattadrūpaguṇaṁ kuryātsamyagīśe sthiraṁ manaḥ||67||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v68" data-pv="w1"><span class="pv-sa pv-src" lang="sa">इतीश्वरपदान्तस्य मार्गस्यास्य पृथक् पृथक्।</span><br />
<span class="pv-iast">Itīśvarapadāntasya mārgasyāsya pṛthak pṛthak|</span><br />
<span class="pv-sa pv-src" lang="sa">यथोपासा तथाख्याता योगिनां योगसिद्धये॥६८॥</span><br />
<span class="pv-iast">Yathopāsā tathākhyātā yogināṁ yogasiddhaye||68||</span></p>

<p class="pv-pair pv-c" data-pv="w1"><span class="pv-sa pv-src" lang="sa">इति श्रीमालिनीविजयोत्तरे तन्त्रे धरणाधिकारः षोडशः॥१६॥</span><br />
<span class="pv-iast">Iti śrīmālinīvijayottare tantre dharaṇādhikāraḥ ṣoḍaśaḥ||16||</span></p>
