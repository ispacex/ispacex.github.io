# Гимн 15 — Bhaktistotranāma pañcadaśaṁ stotram

<p class="pv-pager nosearch" markdown="1">[← Гимн 14 — Jayastotranāma caturdaśaṁ stotram](/ksh/sv/ch14/) · [Гимн 16 — Pāśān-udbhedanāma ṣoḍaśaṁ stotram →](/ksh/sv/ch16/)</p>

<p class="pv-pair pv-c" id="v15.1" data-pv="w1"><span class="pv-sa pv-src" lang="sa">त्रिमलक्षालिनो ग्रन्थाः सन्ति तत्पारगास्तथा।</span><br />
<span class="pv-iast">Trimalakṣālino granthāḥ santi tatpāragāstathā|</span><br />
<span class="pv-sa pv-src" lang="sa">योगिनः पण्डिताः स्वस्थास्त्वद्भक्ता एव तत्त्वतः॥१५.१॥</span><br />
<span class="pv-iast">Yoginaḥ paṇḍitāḥ svasthāstvadbhaktā eva tattvataḥ||15.1||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.2" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मायीयकालनियतिरागाद्याहारतर्पिताः।</span><br />
<span class="pv-iast">Māyīyakālaniyatirāgādyāhāratarpitāḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">चरन्ति सुखिनो नाथ भक्तिमन्तो जगत्तटे॥१५.२॥</span><br />
<span class="pv-iast">Caranti sukhino nātha bhaktimanto jagattaṭe||15.2||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.3" data-pv="w1"><span class="pv-sa pv-src" lang="sa">रुदन्तो वा हसन्तो वा त्वामुच्चैः प्रलपन्त्यमी।</span><br />
<span class="pv-iast">Rudanto vā hasanto vā tvāmuccaiḥ pralapantyamī|</span><br />
<span class="pv-sa pv-src" lang="sa">भक्ताः स्तुतिपदोच्चारोपचाराः पृथगेव ते॥१५.३॥</span><br />
<span class="pv-iast">Bhaktāḥ stutipadoccāropacārāḥ pṛthageva te||15.3||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.4" data-pv="w1"><span class="pv-sa pv-src" lang="sa">न विरक्तो न चापीशो मोक्षाकाङ्क्षी त्वदर्चकः।</span><br />
<span class="pv-iast">Na virakto na cāpīśo mokṣākāṅkṣī tvadarcakaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">भवेयमपि तूद्रिक्तभक्त्यासवरसोन्मदः॥१५.४॥</span><br />
<span class="pv-iast">Bhaveyamapi tūdriktabhaktyāsavarasonmadaḥ||15.4||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.5" data-pv="w1"><span class="pv-sa pv-src" lang="sa">बाह्यं हृदय एवान्तरभिहृत्यैव योऽर्चति।</span><br />
<span class="pv-iast">Bāhyaṁ hṛdaya evāntarabhihṛtyaiva yo'rcati|</span><br />
<span class="pv-sa pv-src" lang="sa">त्वामीश भक्तिपीयूषरसपूरैर्नमामि तम्॥१५.५॥</span><br />
<span class="pv-iast">Tvāmīśa bhaktipīyūṣarasapūrairnamāmi tam||15.5||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.6" data-pv="w1"><span class="pv-sa pv-src" lang="sa">धर्माधर्मात्मनोरन्तः क्रिययोर्ज्ञानयोस्तथा।</span><br />
<span class="pv-iast">Dharmādharmātmanorantaḥ kriyayorjñānayostathā|</span><br />
<span class="pv-sa pv-src" lang="sa">सुखदुःखात्मनोर्भक्ताः किमप्यास्वादयन्त्यहो॥१५.६॥</span><br />
<span class="pv-iast">Sukhaduḥkhātmanorbhaktāḥ kimapyāsvādayantyaho||15.6||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.7" data-pv="w1"><span class="pv-sa pv-src" lang="sa">चराचरपितः स्वामिनप्यन्धा अपि कुष्ठिनः।</span><br />
<span class="pv-iast">Carācarapitaḥ svāminapyandhā api kuṣṭhinaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">शोभन्ते परमुद्दामभवद्भक्तिविभूषणाः॥१५.७॥</span><br />
<span class="pv-iast">Śobhante paramuddāmabhavadbhaktivibhūṣaṇāḥ||15.7||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.8" data-pv="w1"><span class="pv-sa pv-src" lang="sa">शिलोञ्छपिच्छकशिपुविच्छायाङ्गा अपि प्रभो।</span><br />
<span class="pv-iast">Śiloñchapicchakaśipuvicchāyāṅgā api prabho|</span><br />
<span class="pv-sa pv-src" lang="sa">भवद्भक्तिमहोष्मणो राजराजमपीशते॥१५.८॥</span><br />
<span class="pv-iast">Bhavadbhaktimahoṣmaṇo rājarājamapīśate||15.8||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.9" data-pv="w1"><span class="pv-sa pv-src" lang="sa">सुधार्द्रायां भवद्भक्तौ लुठताप्यारुरुक्षुणा।</span><br />
<span class="pv-iast">Sudhārdrāyāṁ bhavadbhaktau luṭhatāpyārurukṣuṇā|</span><br />
<span class="pv-sa pv-src" lang="sa">चेतसैव विभोऽर्चन्ति केचित्त्वामभितः स्थिताः॥१५.९॥</span><br />
<span class="pv-iast">Cetasaiva vibho'rcanti kecittvāmabhitaḥ sthitāḥ||15.9||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.10" data-pv="w1"><span class="pv-sa pv-src" lang="sa">रक्षणीयं वर्धनीयं बहुमान्यमिदं प्रभो।</span><br />
<span class="pv-iast">Rakṣaṇīyaṁ vardhanīyaṁ bahumānyamidaṁ prabho|</span><br />
<span class="pv-sa pv-src" lang="sa">संसारदुर्गतिहरं भवद्भक्तिमहाधनम्॥१५.१०॥</span><br />
<span class="pv-iast">Saṁsāradurgatiharaṁ bhavadbhaktimahādhanam||15.10||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.11" data-pv="w1"><span class="pv-sa pv-src" lang="sa">नाथ ते भक्तजनता यद्यपि त्वयि रागिणी।</span><br />
<span class="pv-iast">Nātha te bhaktajanatā yadyapi tvayi rāgiṇī|</span><br />
<span class="pv-sa pv-src" lang="sa">तथापीर्ष्यां विहायास्यास्तुष्टास्तु स्वामिनी सदा॥१५.११॥</span><br />
<span class="pv-iast">Tathāpīrṣyāṁ vihāyāsyāstuṣṭāstu svāminī sadā||15.11||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.12" data-pv="w1"><span class="pv-sa pv-src" lang="sa">भवद्भावः पुरो भावी प्राप्ते त्वद्भक्तिसम्भवे।</span><br />
<span class="pv-iast">Bhavadbhāvaḥ puro bhāvī prāpte tvadbhaktisambhave|</span><br />
<span class="pv-sa pv-src" lang="sa">लब्धे दुग्धमहाकुम्भे हता दधनि गृध्नुता॥१५.१२॥</span><br />
<span class="pv-iast">Labdhe dugdhamahākumbhe hatā dadhani gṛdhnutā||15.12||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.13" data-pv="w1"><span class="pv-sa pv-src" lang="sa">किमियं न सिद्धिरतुला किं वा मुख्यं न सौख्यमास्रवति।</span><br />
<span class="pv-iast">Kimiyaṁ na siddhiratulā kiṁ vā mukhyaṁ na saukhyamāsravati|</span><br />
<span class="pv-sa pv-src" lang="sa">भक्तिरुपचीयमाना येयं शम्भोः सदातनी भवति॥१५.१३॥</span><br />
<span class="pv-iast">Bhaktirupacīyamānā yeyaṁ śambhoḥ sadātanī bhavati||15.13||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.14" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मनसि मलिने मदीयेमग्ना त्वद्भक्तिमणिलता कष्टम्।</span><br />
<span class="pv-iast">Manasi maline madīyemagnā tvadbhaktimaṇilatā kaṣṭam|</span><br />
<span class="pv-sa pv-src" lang="sa">न निजानपि तनुते तानपौरुषेयान्स्वसम्पदुल्लासान्॥१५.१४॥</span><br />
<span class="pv-iast">Na nijānapi tanute tānapauruṣeyānsvasampadullāsān||15.14||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.15" data-pv="w1"><span class="pv-sa pv-src" lang="sa">भक्तिर्भगवति भवति त्रिलोकनाथे ननूत्तमा सिद्धिः।</span><br />
<span class="pv-iast">Bhaktirbhagavati bhavati trilokanāthe nanūttamā siddhiḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">किं त्वणिमादिकविरहात्सैव न पूर्णेति चिन्ता मे॥१५.१५॥</span><br />
<span class="pv-iast">Kiṁ tvaṇimādikavirahātsaiva na pūrṇeti cintā me||15.15||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.16" data-pv="w1"><span class="pv-sa pv-src" lang="sa">बाह्यतोऽन्तरपि चोत्कटोन्मिषत्त्र्यम्बकस्तवकसौरभाः शुभाः।</span><br />
<span class="pv-iast">Bāhyato'ntarapi cotkaṭonmiṣattryambakastavakasaurabhāḥ śubhāḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">वासयन्त्यपि विरुद्धवासनान्योगिनो निकटवासिनोऽखिलान्॥१५.१६॥</span><br />
<span class="pv-iast">Vāsayantyapi viruddhavāsanānyogino nikaṭavāsino'khilān||15.16||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.17" data-pv="w1"><span class="pv-sa pv-src" lang="sa">ज्योतिरस्ति कथयापि न किञ्चिद्विश्वमप्यतिसुषुप्तमशेषम्।</span><br />
<span class="pv-iast">Jyotirasti kathayāpi na kiñcidviśvamapyatisuṣuptamaśeṣam|</span><br />
<span class="pv-sa pv-src" lang="sa">यत्र नाथ शिवरात्रिपदेऽस्मिन्नित्यमर्चयति भक्तजनस्त्वाम्॥१५.१७॥</span><br />
<span class="pv-iast">Yatra nātha śivarātripade'sminnityamarcayati bhaktajanastvām||15.17||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.18" data-pv="w1"><span class="pv-sa pv-src" lang="sa">सत्त्वं सत्यगुणे शिवे भगवति स्फारीभवत्वर्चने चूडायां विलसन्तु शङ्करपदप्रोद्यद्रजःसङ्चयाः।</span><br />
<span class="pv-iast">Sattvaṁ satyaguṇe śive bhagavati sphārībhavatvarcane cūḍāyāṁ vilasantu śaṅkarapadaprodyadrajaḥsaṅcayāḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">रागादिस्मृतिवासनामपि समुच्छेत्तुं तमो जृम्भतां शम्भो मे भवतात्त्वदात्मविलये त्रैगुण्यवर्गोऽथवा॥१५.१८॥</span><br />
<span class="pv-iast">Rāgādismṛtivāsanāmapi samucchettuṁ tamo jṛmbhatāṁ śambho me bhavatāttvadātmavilaye traiguṇyavargo'thavā||15.18||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v15.19" data-pv="w1"><span class="pv-sa pv-src" lang="sa">संसाराध्वा सुदूरः खरतरविविधव्याधिदग्धाङ्गयष्टिः भोगा नैवोपभुक्ता यदपि सुखमभूज्जातु नन्नो चिराय।</span><br />
<span class="pv-iast">Saṁsārādhvā sudūraḥ kharataravividhavyādhidagdhāṅgayaṣṭiḥ bhogā naivopabhuktā yadapi sukhamabhūjjātu nanno cirāya|</span><br />
<span class="pv-sa pv-src" lang="sa">इत्थं व्यर्थोऽस्मि जातः शशिधरचरणाक्रान्तिकान्तोत्तमाङ्गस्त्वद्भक्तश्चेति तन्मे कुरु सपदि महासम्पदो दीर्घदीर्घाः॥१५.१९॥</span><br />
<span class="pv-iast">Itthaṁ vyartho'smi jātaḥ śaśidharacaraṇākrāntikāntottamāṅgastvadbhaktaśceti tanme kuru sapadi mahāsampado dīrghadīrghāḥ||15.19||</span></p>
