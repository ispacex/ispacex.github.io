# Гимн 2 — Sarvātmaparibhāvanākhyaṁ dvitīyaṁ stotram

<p class="pv-pair pv-c" id="v2.1" data-pv="w1"><span class="pv-sa pv-src" lang="sa">अग्नीषोमरविब्रह्मविष्णुस्थावरजङ्गम।</span><br />
<span class="pv-iast">Agnīṣomaravibrahmaviṣṇusthāvarajaṅgama|</span><br />
<span class="pv-sa pv-src" lang="sa">स्वरूप बहुरूपाय नमः संविन्मयाय ते॥२.१॥</span><br />
<span class="pv-iast">Svarūpa bahurūpāya namaḥ saṁvinmayāya te||2.1||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.2" data-pv="w1"><span class="pv-sa pv-src" lang="sa">विश्वेन्धनमहाक्षारानुलेपशुचिवर्चसे।</span><br />
<span class="pv-iast">Viśvendhanamahākṣārānulepaśucivarcase|</span><br />
<span class="pv-sa pv-src" lang="sa">महानलाय भवते विश्वैकहविषे नमः॥२.२॥</span><br />
<span class="pv-iast">Mahānalāya bhavate viśvaikahaviṣe namaḥ||2.2||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.3" data-pv="w1"><span class="pv-sa pv-src" lang="sa">परमामृतसान्द्राय शीतलाय शिवाग्नये।</span><br />
<span class="pv-iast">Paramāmṛtasāndrāya śītalāya śivāgnaye|</span><br />
<span class="pv-sa pv-src" lang="sa">कस्मैचिद्विश्वसम्प्लोषविषमाय नमोऽस्तु ते॥२.३॥</span><br />
<span class="pv-iast">Kasmaicidviśvasamploṣaviṣamāya namo'stu te||2.3||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.4" data-pv="w1"><span class="pv-sa pv-src" lang="sa">महादेवाय रुद्राय शङ्कराय शिवाय ते।</span><br />
<span class="pv-iast">Mahādevāya rudrāya śaṅkarāya śivāya te|</span><br />
<span class="pv-sa pv-src" lang="sa">महेश्वरायापि नमः कस्मैचिन्मन्त्रमूर्तये॥२.४॥</span><br />
<span class="pv-iast">Maheśvarāyāpi namaḥ kasmaicinmantramūrtaye||2.4||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.5" data-pv="w1"><span class="pv-sa pv-src" lang="sa">नमो निकृत्तनिःशोषत्रैलोक्यविगलद्वसा-।</span><br />
<span class="pv-iast">Namo nikṛttaniḥśoṣatrailokyavigaladvasā-|</span><br />
<span class="pv-sa pv-src" lang="sa">वसेकविषमायापि मङ्गलाय शिवाग्नये॥२.५॥</span><br />
<span class="pv-iast">Vasekaviṣamāyāpi maṅgalāya śivāgnaye||2.5||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.6" data-pv="w1"><span class="pv-sa pv-src" lang="sa">समस्तलक्षनायोग एव यस्योपलक्षणम्।</span><br />
<span class="pv-iast">Samastalakṣanāyoga eva yasyopalakṣaṇam|</span><br />
<span class="pv-sa pv-src" lang="sa">तस्मै नमोऽस्तु देवाय कस्मैचिदपि शम्भवे॥२.६॥</span><br />
<span class="pv-iast">Tasmai namo'stu devāya kasmaicidapi śambhave||2.6||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.7" data-pv="w1"><span class="pv-sa pv-src" lang="sa">वेदागमविरुद्धाय वेदागमविधायिने।</span><br />
<span class="pv-iast">Vedāgamaviruddhāya vedāgamavidhāyine|</span><br />
<span class="pv-sa pv-src" lang="sa">वेदागमसतत्त्वाय गुह्याय स्वामिने नमः॥२.७॥</span><br />
<span class="pv-iast">Vedāgamasatattvāya guhyāya svāmine namaḥ||2.7||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.8" data-pv="w1"><span class="pv-sa pv-src" lang="sa">संसारैकनिमित्ताय संसारैकविरोधिने।</span><br />
<span class="pv-iast">Saṁsāraikanimittāya saṁsāraikavirodhine|</span><br />
<span class="pv-sa pv-src" lang="sa">नमः सम्साररूपाय निःसंसाराय शम्भवे॥२.८॥</span><br />
<span class="pv-iast">Namaḥ samsārarūpāya niḥsaṁsārāya śambhave||2.8||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.9" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मूलाय मध्यायाग्राय मूलमध्याग्रमूर्तये।</span><br />
<span class="pv-iast">Mūlāya madhyāyāgrāya mūlamadhyāgramūrtaye|</span><br />
<span class="pv-sa pv-src" lang="sa">क्षीनाग्रमध्यमूलाय नमः पूर्णाय शम्भवे॥२.९॥</span><br />
<span class="pv-iast">Kṣīnāgramadhyamūlāya namaḥ pūrṇāya śambhave||2.9||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.10" data-pv="w1"><span class="pv-sa pv-src" lang="sa">नमः सुकृतसम्भरविपाकः सकृदप्यसौ।</span><br />
<span class="pv-iast">Namaḥ sukṛtasambharavipākaḥ sakṛdapyasau|</span><br />
<span class="pv-sa pv-src" lang="sa">यस्य नामग्रहस्तस्मै दुर्लभाय शिवाय ते॥२.१०॥</span><br />
<span class="pv-iast">Yasya nāmagrahastasmai durlabhāya śivāya te||2.10||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.11" data-pv="w1"><span class="pv-sa pv-src" lang="sa">नमश्चराचराकारपरेतनिचयैः सदा।</span><br />
<span class="pv-iast">Namaścarācarākāraparetanicayaiḥ sadā|</span><br />
<span class="pv-sa pv-src" lang="sa">क्रीडते तुभ्यमेकस्मैचिन्मयाय कपालिने॥२.११॥</span><br />
<span class="pv-iast">Krīḍate tubhyamekasmaicinmayāya kapāline||2.11||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.12" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मायाविने विशुद्धाय गुह्याय प्रकटात्मने।</span><br />
<span class="pv-iast">Māyāvine viśuddhāya guhyāya prakaṭātmane|</span><br />
<span class="pv-sa pv-src" lang="sa">सूक्ष्माय विश्वरूपाय नमश्चित्राय शम्भवे॥२.१२॥</span><br />
<span class="pv-iast">Sūkṣmāya viśvarūpāya namaścitrāya śambhave||2.12||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.13" data-pv="w1"><span class="pv-sa pv-src" lang="sa">ब्रह्मेन्द्रविष्णुनिर्व्यूढजगत्संहारकेलये।</span><br />
<span class="pv-iast">Brahmendraviṣṇunirvyūḍhajagatsaṁhārakelaye|</span><br />
<span class="pv-sa pv-src" lang="sa">आश्चर्यकरणीयाय नमस्ते सर्वशक्तये॥२.१३॥</span><br />
<span class="pv-iast">Āścaryakaraṇīyāya namaste sarvaśaktaye||2.13||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.14" data-pv="w1"><span class="pv-sa pv-src" lang="sa">तटेष्वेव परिभ्रान्तैर्लब्धास्तास्ता विभूतयः।</span><br />
<span class="pv-iast">Taṭeṣveva paribhrāntairlabdhāstāstā vibhūtayaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">यस्य तस्मै नमस्तुभ्यमगाधहरसिन्धवे॥२.१४॥</span><br />
<span class="pv-iast">Yasya tasmai namastubhyamagādhaharasindhave||2.14||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.15" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मायामयजगत्सान्द्रपङ्कमध्याधिवासिने।</span><br />
<span class="pv-iast">Māyāmayajagatsāndrapaṅkamadhyādhivāsine|</span><br />
<span class="pv-sa pv-src" lang="sa">अलेपाय नमः शम्भुशतपत्राय शोभिने॥२.१५॥</span><br />
<span class="pv-iast">Alepāya namaḥ śambhuśatapatrāya śobhine||2.15||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.16" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मङ्गलाय पवित्राय निधये भूषणात्मने।</span><br />
<span class="pv-iast">Maṅgalāya pavitrāya nidhaye bhūṣaṇātmane|</span><br />
<span class="pv-sa pv-src" lang="sa">प्रियाय परमार्थाय सर्वोत्कृष्टाय ते नमः॥२.१६॥</span><br />
<span class="pv-iast">Priyāya paramārthāya sarvotkṛṣṭāya te namaḥ||2.16||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.17" data-pv="w1"><span class="pv-sa pv-src" lang="sa">नमः सततबद्धाय नित्यनिर्मुक्तिभागिने।</span><br />
<span class="pv-iast">Namaḥ satatabaddhāya nityanirmuktibhāgine|</span><br />
<span class="pv-sa pv-src" lang="sa">बन्धमोक्षविहीनाय कस्मैचिदपि शम्भवे॥२.१७॥</span><br />
<span class="pv-iast">Bandhamokṣavihīnāya kasmaicidapi śambhave||2.17||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.18" data-pv="w1"><span class="pv-sa pv-src" lang="sa">उपहासैकसारेऽस्मिन्नेतावति जगत्त्रये।</span><br />
<span class="pv-iast">Upahāsaikasāre'sminnetāvati jagattraye|</span><br />
<span class="pv-sa pv-src" lang="sa">तुभ्यमेवाद्वितीयाय नमो नित्यसुखासिने॥२.१८॥</span><br />
<span class="pv-iast">Tubhyamevādvitīyāya namo nityasukhāsine||2.18||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.19" data-pv="w1"><span class="pv-sa pv-src" lang="sa">दक्षिणाचारसाराय वामाचाराभिलाषिणे।</span><br />
<span class="pv-iast">Dakṣiṇācārasārāya vāmācārābhilāṣiṇe|</span><br />
<span class="pv-sa pv-src" lang="sa">सर्वाचाराय शर्वाय निराचाराय ते नमः॥२.१९॥</span><br />
<span class="pv-iast">Sarvācārāya śarvāya nirācārāya te namaḥ||2.19||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.20" data-pv="w1"><span class="pv-sa pv-src" lang="sa">यथा तथापि यः पूज्यो यत्र तत्रापि योऽर्चितः।</span><br />
<span class="pv-iast">Yathā tathāpi yaḥ pūjyo yatra tatrāpi yo'rcitaḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">योऽपि वा सोऽपि वा योऽसौ देवस्तस्मै नमोऽस्तु ते॥२.२०॥</span><br />
<span class="pv-iast">Yo'pi vā so'pi vā yo'sau devastasmai namo'stu te||2.20||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.21" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मुमुक्षुजनसेव्याय सर्वसन्तापहारिणे।</span><br />
<span class="pv-iast">Mumukṣujanasevyāya sarvasantāpahāriṇe|</span><br />
<span class="pv-sa pv-src" lang="sa">नमो विततलावण्यवराय वरदाय ते॥२.२१॥</span><br />
<span class="pv-iast">Namo vitatalāvaṇyavarāya varadāya te||2.21||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.22" data-pv="w1"><span class="pv-sa pv-src" lang="sa">सदा निरन्तरानन्दरसनिर्भरिताखिल-।</span><br />
<span class="pv-iast">Sadā nirantarānandarasanirbharitākhila-|</span><br />
<span class="pv-sa pv-src" lang="sa">त्रिलोकाय नमस्तुभ्यं स्वामिने नित्यपर्वणे॥२.२२॥</span><br />
<span class="pv-iast">Trilokāya namastubhyaṁ svāmine nityaparvaṇe||2.22||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.23" data-pv="w1"><span class="pv-sa pv-src" lang="sa">सुखप्रधानसंवेद्यसम्भोगैर्भजते च यत्।</span><br />
<span class="pv-iast">Sukhapradhānasaṁvedyasambhogairbhajate ca yat|</span><br />
<span class="pv-sa pv-src" lang="sa">त्वामेव तस्मै घोराय शक्तिवृन्दाय ते नमः॥२.२३॥</span><br />
<span class="pv-iast">Tvāmeva tasmai ghorāya śaktivṛndāya te namaḥ||2.23||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.24" data-pv="w1"><span class="pv-sa pv-src" lang="sa">मुनीनामप्यविज्ञेयं भक्तिसम्बन्धचेष्टिताः।</span><br />
<span class="pv-iast">Munīnāmapyavijñeyaṁ bhaktisambandhaceṣṭitāḥ|</span><br />
<span class="pv-sa pv-src" lang="sa">आलिङ्गन्त्यपि यं तस्मै कस्मैचिद्भवते नमः॥२.२४॥</span><br />
<span class="pv-iast">Āliṅgantyapi yaṁ tasmai kasmaicidbhavate namaḥ||2.24||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.25" data-pv="w1"><span class="pv-sa pv-src" lang="sa">परमामृतकोशाय परमामृतराशये।</span><br />
<span class="pv-iast">Paramāmṛtakośāya paramāmṛtarāśaye|</span><br />
<span class="pv-sa pv-src" lang="sa">सर्वपारम्यपारम्यप्राप्याय भवते नमः॥२.२५॥</span><br />
<span class="pv-iast">Sarvapāramyapāramyaprāpyāya bhavate namaḥ||2.25||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.26" data-pv="w1"><span class="pv-sa pv-src" lang="sa">महामन्त्रमयं नौमि रूपं ते स्वच्छशीतलम्।</span><br />
<span class="pv-iast">Mahāmantramayaṁ naumi rūpaṁ te svacchaśītalam|</span><br />
<span class="pv-sa pv-src" lang="sa">अपूर्वमोदसुभगं परामृतरसोल्वणम्॥२.२६॥</span><br />
<span class="pv-iast">Apūrvamodasubhagaṁ parāmṛtarasolvaṇam||2.26||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.27" data-pv="w1"><span class="pv-sa pv-src" lang="sa">स्वातन्त्र्यामृतपूर्णत्वदैक्यख्यातिमहापटे।</span><br />
<span class="pv-iast">Svātantryāmṛtapūrṇatvadaikyakhyātimahāpaṭe|</span><br />
<span class="pv-sa pv-src" lang="sa">चित्रं नास्त्येव यत्रेश तन्नौमि तव शासनम्॥२.२७॥</span><br />
<span class="pv-iast">Citraṁ nāstyeva yatreśa tannaumi tava śāsanam||2.27||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.28" data-pv="w1"><span class="pv-sa pv-src" lang="sa">सर्वाशङ्कासनिं सर्वालक्ष्मीकालानलं तथा।</span><br />
<span class="pv-iast">Sarvāśaṅkāsaniṁ sarvālakṣmīkālānalaṁ tathā|</span><br />
<span class="pv-sa pv-src" lang="sa">सर्वामङ्गल्यकल्पान्तं मार्गं माहेश्वरं नुमः॥२.२८॥</span><br />
<span class="pv-iast">Sarvāmaṅgalyakalpāntaṁ mārgaṁ māheśvaraṁ numaḥ||2.28||</span></p>

<hr class="pv-rule" />

<p class="pv-pair pv-c" id="v2.29" data-pv="w1"><span class="pv-sa pv-src" lang="sa">जय देव नमो नमोऽस्तु ते सकलं विश्वमिदं तवाश्रितम्।</span><br />
<span class="pv-iast">Jaya deva namo namo'stu te sakalaṁ viśvamidaṁ tavāśritam|</span><br />
<span class="pv-sa pv-src" lang="sa">जगतां परमेश्वरो भवान्परमेकः शरणागतोऽस्मि ते॥२.२९॥</span><br />
<span class="pv-iast">Jagatāṁ parameśvaro bhavānparamekaḥ śaraṇāgato'smi te||2.29||</span></p>
